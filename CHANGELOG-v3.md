# Changelog v3

- Interested remains the default signed-in view.
- Replaced Interested card grid with grouped tables.
- Soon = next 30 days.
- Future = 31–90 days.
- Far future = more than 90 days away.
- Events remain sorted by `start_at` ascending.
- Group tables show date/time, event title, support, venue, age restriction, and event/ticket links.
- Review and All Events behavior remain unchanged.
- Continues to use the deployed schema's `start_at` / `end_at` fields.
